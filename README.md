# Algebra Lineal Numerica Para Aprendizaje Estadistico

Este repositorio contiene el código fuente de mi libro de apuntes del curso de Geometría y Álgebra Lineal para Aprendizaje Estadístico, edicion 2026, de Facultad de Ciencias Sociales y Comunicación, a cargo de Diego Armentano y Manuel Hernández.

Basado en los [materiales del curso](https://github.com/diegoax/ALNAE-2026/) y la obra de Gilbert Strang, principalmente sus [lecturas de OpenCourseWare](https://ocw.mit.edu/courses/18-065-matrix-methods-in-data-analysis-signal-processing-and-machine-learning-spring-2018/).

👉 **Puedes leer el libro aquí:** <https://mtrias.github.io/alnae/>
